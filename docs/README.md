## Design research

[design/README.md](./design/README.md) indexes design research and design briefs. That material is a dated research snapshot and contains recommendations and assessments that may no longer match the current UI. Check the live UI source before treating it as current behavior or design direction.

## Documentation status

Guides, examples, and plans explain intended use or record a point-in-time view. They do not prove that a command succeeds, an integration is currently available, or a security control is effective. Confirm relevant package source, manifests, and current verification results before relying on time-sensitive claims.
